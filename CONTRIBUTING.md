# Contributing

The repository is currently in a controlled pre-release phase.

Before submitting a code change:

1. open an issue describing the scientific or reproducibility need;
2. identify whether the change affects canonical calculations, reporting only,
   rendering only or documentation only;
3. preserve backward compatibility where scientifically defensible;
4. update tests, checksums, documentation and the changelog;
5. never replace a failed output silently.

Changes to equations, tail calibration, tie handling, Mahalanobis geometry,
empirical tiers or add-on definitions require explicit methodological review.
