# Metadata files

## `script_manifest.csv`

Maps each repository script to its supplied source filename, role, canonical
status and initial SHA-256 checksum.

## `data_manifest.csv`

Template for documenting input and derived datasets, including provenance,
version, licence, redistribution status and checksum.

## `package_requirements.csv`

Lists R package dependencies detected from the tutorial scripts. Exact versions
remain pending until the clean-machine release environment is frozen.
